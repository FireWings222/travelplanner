# TravelPlanner UI 개선을 위한 유사 서비스 조사

## 1. 조사 범위와 방법

- 조사일: 2026-11-23
- 대상: TravelPlanner 화면 5개(홈 검색, 경로 비교, 여행 일정, 일일투어, 비용 비교)와 기능이 겹치는 국내외 서비스 16개
- 방법: 웹 검색, 공개 웹 페이지 읽기(서비스 공개 페이지, 앱스토어 설명, 공식 도움말, 언론 보도, 이용 안내 글)
- 로그인 뒤에만 보이는 화면(일정 편집, 가계부 등)은 앱스토어 설명과 보도 자료로 대신 확인했다.
- 표기 기준
  - "확인": 조사일에 해당 페이지를 직접 읽어 확인한 내용. 문장 끝에 출처 번호([S번호])를 붙였다.
  - "검색 요약": 검색 결과 요약문에서만 확인했고 원문 페이지는 읽지 못한 내용.
  - "미확인": 페이지로 확인하지 못했고 일반 지식에 기댄 내용. 설계에 쓰기 전에 실제 화면 확인이 필요하다.
- 화면 배치(좌우 분할, 고정 위치 등)는 텍스트로 변환된 페이지에서 알 수 없는 경우가 많아 미확인 비중이 높다.
- TravelPlanner 쪽 적용 가능 여부는 저장소의 `templates/`, `static/js/`, `static/css/` 파일을 읽어 판단했다.

## 3. 같은 기능 묶음을 제공하는 서비스가 있는지

- 조사한 16개 서비스 가운데 "구간별 교통수단 비용 비교, 일자별 일정과 비용 계산, 투어 대 자유여행 비용 비교"를 한 서비스에서 함께 제공하는 사례는 확인하지 못했다. "일일투어 자유여행 비용 비교 서비스"로 검색한 결과에도 전용 서비스는 나오지 않았고, 블로그 비교 글과 예약 앱 소개만 나왔다.
- 기능이 두 가지 이상 겹치는 서비스는 다음과 같다.
  - Rome2Rio: 구간별 교통수단, 시간, 요금 범위 비교가 TravelPlanner 경로 비교 화면과 가장 가깝다. 인원 합계, 왕복, 관광 일정, 투어 비교는 없다.
  - Wanderlog: 일정 편집, 지도, 장소 간 이동 시간, 예산이 TravelPlanner 여행 일정 화면과 가장 가깝다. 예산은 사용자가 입력한 지출을 합산하는 방식이다.
  - NOL(트리플 일정 기능 포함): 일정, 지도, 예약을 한 앱에서 제공한다. 교통수단별 비용 비교와 투어 대 자유여행 비교 설명은 없다.
- 투어 대 자유여행 비교는 Trip.com 안내 글처럼 서술형 표로만 존재했다. 같은 관광지 묶음을 기준으로 금액과 시간을 계산해 나란히 보여 주는 화면은 조사 범위 안에서 찾지 못했다. 조사하지 않은 서비스에 있을 가능성은 남아 있다.

## 4. 화면별 디자인 패턴

### 4.1 검색 입력

| 서비스 | 입력 방식 | 구분 |
|---|---|---|
| Rome2Rio | 입력란 2개("Travel from", "To")와 출발지/목적지 맞바꿈 버튼, 날짜와 인원은 첫 검색에서 받지 않고 구간 선택 뒤에 입력 | 확인(S12, S13) |
| KAYAK | 한 줄 폼, 왕복 선택, 출발지, 목적지, 출발일, 귀국일, "1 adult, Economy" 요약 버튼, 검색 버튼 순서 | 확인(S19) |
| Skyscanner | 검색 상자 위에 여정 종류 선택, 좌석 등급과 인원을 같은 폼에서 선택, 날짜 칸에서 "Whole month" 선택 가능 | 확인(S18) |
| 대한민국 구석구석 AI 콕콕 플래너 | 지역, 기간(당일 등), 주제(실내 여행지, 카페 등)를 차례로 선택하는 단계형 | 확인(S7) |
| 마이로 | 도시와 날짜를 고르고 장소를 담으면 일정 생성 | 검색 요약(S6) |
| KAYAK, Skyscanner 인원 선택 | 요약 버튼을 누르면 성인/아동별 +, - 버튼이 있는 팝오버 표시 | 미확인 |
| 항공 검색 서비스 날짜 선택 | 달력 한 개에서 가는 날과 오는 날을 범위로 선택 | 미확인 |

- TravelPlanner 홈은 입력 항목이 9개(출발지, 목적지, 시작일, 종료일, 성인, 아동, 예산, 선호 교통수단, 여행 유형)로, 조사한 검색 폼(2~6개)보다 많다.
- Rome2Rio처럼 필수 항목(출발지, 목적지, 날짜, 인원)과 선택 항목(예산, 선호 교통수단, 여행 유형)을 나누는 구성이 참고가 된다.

### 4.2 경로와 교통 비교 결과

| 서비스 | 결과 표시 방식 | 구분 |
|---|---|---|
| Rome2Rio | 번호가 붙은 경로 카드 8개를 세로로 나열, 카드마다 제목(예: "Fly from Gimpo International Airport"), 구간 목록, 교통수단 아이콘, 소요 시간(예: "2h 42m"), 요금 범위(예: "32,092~143,196원") 표시 | 확인(S12) |
| Rome2Rio | 첫 번째 카드에만 "best" 배지 표시, 가장 싼 경로와 가장 빠른 경로는 배지가 아니라 문답(Q&A) 블록으로 안내, 다만 상단 요약의 "Cheapest Price"(기차와 카페리 58,915원)와 문답의 "가장 싼 방법은 항공" 안내가 서로 다름 | 확인(S12) |
| Rome2Rio | 선택한 경로 요약에 통계 타일 3개(주간 운행 횟수, 평균 소요 시간, 최저 요금), 지도와 "Launch map view" 버튼, 거리와 소요 시간 표시 | 확인(S12) |
| Rome2Rio | 교통수단 옆 화살표를 누르면 구간, 정류장, 요금 추정이 펼쳐지는 구조, 자동차는 거리, 시간, 연료비 표시 | 확인(S13) |
| Skyscanner | 결과 상단에 Best(기본값), Cheapest, Fastest 정렬 탭, 좌측에 필터(직항 여부, 출발 시간대, 소요 시간, 항공사, 공항) | 확인(S18) |
| KAYAK | Cheapest, Best(기본값), Quickest 정렬, Best는 가격과 소요 시간, 경유 횟수를 함께 반영, 같은 항공편은 한 카드로 묶고 가장 싼 판매처를 먼저 표시 | 확인(S20) |
| Google Flights | Best, Cheapest 2개 탭, 저렴한 요금은 녹색 글자로 강조 | 확인(S21) |
| Skyscanner, KAYAK 정렬 탭 | 탭 안에 해당 기준의 최저 가격과 소요 시간을 함께 표시 | 미확인 |
| 카카오맵, 네이버 지도 대중교통 결과 | 경로 카드에 총 소요 시간, 요금, 환승 횟수, 교통수단별 색 막대 표시 | 미확인 |

- TravelPlanner 경로 비교 화면은 표(환승, 편도 1인, 편도 일행, 왕복 일행)와 "경로 추천" 묶음을 따로 그린다. 조사한 서비스는 추천 표시를 결과 카드에 배지로 붙이거나(Rome2Rio) 정렬 탭으로 제공한다(Skyscanner, KAYAK, Google Flights).

### 4.8 화면 직접 확인

지도 교사가 Rome2Rio의 여행 지도와 Wanderlog의 경로 편집을 참고 대상으로 골라, 2026-11-23에 Claude Code가 앱 안 브라우저(1366px 폭)로 두 사이트를 열어 화면을 확인했다. 캡처는 저작권 때문에 저장소에 넣지 않았다.

| 서비스 | 화면 | 본 내용 |
|---|---|---|
| Rome2Rio | 경로 목록(`/map/Seoul/Jeju-City`) | 왼쪽에 아이콘만 있는 세로 메뉴(교통, 숙소, 할 일, 장소), 가운데 경로 카드 목록(폭 약 40%), 오른쪽에 화면 높이를 다 쓰는 둥근 모서리 지도 |
| Rome2Rio | 경로 카드 | 흰 카드에 경로 제목, 교통수단 아이콘과 소요 시간 한 줄, 오른쪽 끝에 강조색(자홍색) 요금 범위와 꺾쇠, 첫 카드 오른쪽 위에 작은 녹색 "BEST" 배지 |
| Rome2Rio | 경로 상세(항공 경로 선택 시) | 목록이 상세로 바뀌고 위에 날짜, 왕복 추가, 인원 칩, "Filters", "Sort: Best" 버튼, 편마다 "FASTEST", "CHEAPEST" 녹색 배지와 자홍색 가격 |
| Rome2Rio | 지도 | 선택한 경로를 청록색 선으로 그리고, 출발지와 도착지에 흰 말풍선 라벨(공항 이름, 소요 시간) 표시, 지도 위에 "Transport", "Hotels" 전환 버튼 |
| Wanderlog | 홈 시연 화면 | 왼쪽 일정 목록, 오른쪽 지도의 좌우 분할 확인. 일정은 "Flights", "Hotels and lodging"처럼 접고 펼치는 구역으로 나뉘고, 구역마다 회색 바탕 카드와 "..." 메뉴 |
| Wanderlog | 지도 | 장소 종류별 색이 다른 번호 핀, 오른쪽 위 작은 아이콘 버튼, 강조색은 주황색 하나(시작 버튼, 가입 버튼) |
| 두 서비스 공통 | 시각 표현 | 흰 바탕과 옅은 회색 구역, 강조색 하나, 그라데이션과 큰 그림자 없음. 세련된 인상은 장식보다 지도와 목록을 나란히 두는 배치에서 나옴 |

- 4.3절의 "Wanderlog 웹 좌우 분할 배치"(미확인)는 이 확인으로 "확인"이 됐다.
- 드래그 앤 드롭 동작은 로그인 뒤 화면이라 직접 해 보지 못했다. 지도 교사가 시연 영상으로 본 내용을 참고한다.
- 친구 초대(일정 함께 편집)는 지도 교사가 마음에 들어 했지만, 지금 범위에서는 만들지 않고 참고만 한다.

## 5. TravelPlanner 적용 후보

"프론트엔드만으로 가능"은 Java 코드를 고치지 않고 HTML 템플릿, CSS, JS만 수정한다는 뜻이다.

| 패턴 | 참고 서비스 | 적용 화면 | 프론트엔드만으로 가능 여부 | 근거와 주의점 |
|---|---|---|---|---|
| 필수 항목과 선택 항목 분리(선택 항목은 접기) | Rome2Rio, KAYAK | 홈 | 가능 | `index.html`의 폼 배치와 CSS만 변경 |
| 출발지/목적지 맞바꿈 버튼 | Rome2Rio | 홈 | 가능 | 입력란 2개 값 교환 JS |
| 인원 +, - 버튼(숫자 입력 대체) | KAYAK, Skyscanner(미확인) | 홈 | 가능 | 기존 `adults`, `children` 입력란 유지, 버튼만 추가 |
| 추천 배지를 경로 행에 직접 표시 | Rome2Rio("best") | 경로 비교 | 가능 | `routes.js`가 응답의 `recommendations`를 이미 받아 별도 묶음으로 표시 중 |
| 정렬 탭(추천순, 최저가, 최단 시간) | Skyscanner, KAYAK, Google Flights | 경로 비교 | 가능 | 응답에 경로별 비용, 환승 횟수, 소요 시간(`Journey.minutes`) 포함 확인, 화면에서 재정렬 |

## 6. 미확인 사항

- 클룩 웹 페이지: 접근 차단(HTTP 403)으로 상품 카드, 필터, 상세 화면 구성을 읽지 못했다. 앱스토어 설명만 확인했다.
- 마이리얼트립: 홈 화면의 카드 구성만 확인했다. 투어 목록의 필터와 정렬, 상품 상세의 포함/불포함 표기, 하단 고정 예약 버튼은 확인하지 못했다.
- 마이로(MYRO): 앱스토어 페이지를 직접 열지 못했고(HTTP 404), 검색에 나온 주소 `myro.co.kr`은 조사일에 여행과 무관한 내용을 보여 주었다. 현재 운영 여부, 국내 도시 지원 범위, 화면 구성은 확인이 필요하다. 드래그 앤 드롭과 이동 시간 재계산은 2024년 9월 기사 기준이다.
- 트리플: 앱스토어 안내문의 종료일(11월 3일)에는 연도가 없다. 2026년 9월 8일 보도(S4)에 "11월에 트리플도 NOL에 흡수될 예정"이라는 내용이 있어 2026년으로 판단했다. 버전 기록에는 10월 중순부터 NOL로 계정과 여행 일정을 옮기는 기능을 제공한다는 안내가 있다. 9월 8일은 NOL 인터파크투어, NOL 티켓 통합을 발표한 날이며 실제 통합 시점은 기사에 따로 적혀 있지 않다. 일정과 가계부가 NOL로 어느 범위까지 옮겨졌는지는 확인하지 못했다.
- NOL 여행 일정: 기능 설명은 출시 보도(S5) 기준이고 기사 게재일을 페이지에서 확인하지 못했다. 현재 앱 화면은 확인하지 못했다.
- 카카오맵, 네이버 지도: 길찾기 결과 화면의 요금 표시, 정렬 옵션, 택시 예상 요금은 공식 페이지에서 확인하지 못했다. 네이버 지도의 교통수단 통합과 기차 예매 연동은 검색 요약으로만 확인했다.
- Wanderlog: 웹 화면의 좌우 분할 배치, 일자별 구역, 예산 화면의 1인/총액 표시는 확인하지 못했다(도움말 사이트 접근 차단).
- Skyscanner, KAYAK, Google Flights: 인원 선택 팝오버, 날짜 범위 달력, 정렬 탭 안의 가격 표시, 금액이 1인 기준인지 총액인지는 확인하지 못했다.
- TripIt: 일정 타임라인 화면 구성은 공개 페이지에 설명이 없어 확인하지 못했다.
- 4장 표에서 "미확인"으로 적은 행은 모두 화면을 직접 보고 확인해야 한다.
- TravelPlanner 쪽 응답 필드 3건(방문지 좌표, 경로 소요 시간, 비용 비교 1인 금액)은 `dto/Travel.java`, `pricing/Pricing.java`, `service/JourneyService.java`를 읽어 모두 있음을 확인했다(2026-11-23). 실제 응답 값은 키 없는 샘플 모드에서만 확인했다.

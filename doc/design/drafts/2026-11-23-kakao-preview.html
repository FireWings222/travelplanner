두 시안 공통

  • 상단 4단계 표시와 여행 조건 요약(결정 대기 진단 1번)
  • 교통 왕복, 현지 일정, 일일투어를 합친 여행 견적과 예산 막대(진단 2번)
  • 추천 경로는 꼬리표 하나로만 표시하고 눌러서 바로 적용(진단 3번)
  • 장소 사이에 이동 구간을 끼워 넣어 반복 카드 제거(진단 4, 5번)
  • 그라데이션, 장식 카드, 큰 머리말 제목 없음(결정 0005)
  • 글자는 거의 검정, 본문 15px 이상, 금액과 제목은 굵게

실제 앱에 넣을 때 확인할 것

  • 글꼴: 실제 앱은 site.css에 지정된 Pretendard를 씀. 시안은 Pretendard가 없는 기기에서 Inter와 Noto Sans KR로 대신 보여 줌
  • 추천 경로 적용: 응답의 경로 조합(modes)을 구간 순서대로 선택값에 넣는 방식이라 프론트엔드만으로 가능해 보임. 구현 때 확인 필요
  • 장소를 옮긴 뒤 금액: 시안은 직선 거리만 보여 주고, 실제 앱은 기존 일정 계산 API로 다시 계산
  • 지도: 실제 앱은 카카오맵(JavaScript SDK)으로 구현. 시안의 약도는 자리와 오버레이(경로선, 이름표, 날짜 핀) 모양을 보여 주는 용도라 실제 지형과 다름
  • 도착 시각: 매일 09:00 출발로 가정하고 머무는 시간과 이동 시간을 더한 값. 이동 시간을 모르는 구간 뒤는 "시간 미정"으로 표시
  • 모바일 끌어서 옮기기: 터치 지원 라이브러리 사용 여부를 따로 결정

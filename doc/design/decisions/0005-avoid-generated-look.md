# 0005. AI가 만든 것처럼 보이는 디자인을 피함

| 항목 | 내용 |
|---|---|
| 상태 | 결정(판단 기준은 시안 단계에서 보완) |
| 결정일 | 2026-11-23 |
| 결정한 사람 | 지도 교사 |
| 관련 문서 | [현행 UI 진단](../research/2026-11-23-ui-diagnosis.md) |

## 배경

포트폴리오는 학생이 직접 만든 결과물로 보여야 한다. AI 도구로 만든 화면에서 자주 보이는 형태(템플릿 같은 히어로, 모든 요소에 같은 둥근 카드와 그림자)가 많으면 면접관에게 "생성된 화면"이라는 인상을 줄 수 있다.

## 선택지

| 선택지 | 장점 | 단점 | 프론트엔드만으로 가능 |
|---|---|---|---|
| A. 기준 없이 시안별로 판단 | 빠름 | 사람마다 판단이 달라짐 | 가능 |
| B. 판단 기준 목록을 두고 시안마다 점검 | 같은 기준으로 비교 가능, 학생에게 설명 가능 | 기준을 계속 다듬어야 함 | 가능 |

## 결정

시안을 만들 때 아래 판단 기준으로 점검한다. 기준은 시안을 검토하면서 추가하고 고친다.

## 판단 기준(초안)

| 피할 것 | 현재 화면 사례 | 대신 할 것 |
|---|---|---|
| 내용과 상관없는 장식용 히어로 블록 | 홈 오른쪽 초록 그라데이션 카드(눌러도 반응 없음) | 실제 기능(예: 샘플 여행 바로 보기)이나 실제 데이터로 채움 |
| 모든 화면에 같은 작은 영문식 머리말과 아주 큰 제목 | 화면마다 "목적지까지 이동" 같은 작은 초록 글씨와 52px 제목 | 작업 화면은 제목을 작게, 결과를 위로 |
| 모든 묶음에 같은 둥근 모서리, 테두리, 그림자 | `.panel` 카드가 모든 구역에 반복 | 구역 구분은 여백과 구분선으로, 카드는 눌러서 고르는 대상에만 |
| 숫자 타일 나열 | 화면마다 회색 타일 3~4개 | 판단에 필요한 숫자 하나를 크게, 나머지는 문장이나 표로 |
| 의미 없는 그라데이션, 장식 아이콘 | 이미지 없는 투어 카드의 빈 그라데이션 | 이미지가 없으면 영역을 줄이거나 지명, 동선 같은 실제 정보 표시 |
| 일반적인 문구 | "가까운 곳으로, 우리나라 여행." | 이 앱만 할 수 있는 말(예: 교통비와 현지 비용을 한 번에 계산) |
| 너무 좁은 글자 간격 | 제목 `letter-spacing: -.085em` | 한글 제목은 기본값에 가깝게 |

## 근거

판단 기준의 "현재 화면 사례"는 2026-11-23 현행 진단에서 캡처로 확인한 내용이다. "피할 것" 목록은 AI 생성 화면에서 자주 보이는 형태에 대한 일반적인 관찰이며, 조사로 입증한 내용은 아니다.

## 영향

- 시안 검토 때 이 표로 점검한다.
- 학생이 의도해서 넣은 디자인 요소(브랜드 색, 로고 등)는 학생과 상의한 뒤 바꾼다.

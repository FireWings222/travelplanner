# 0014. 홈 여행 조건 폼의 폭과 입력 줄 정리

| 항목 | 내용 |
|---|---|
| 상태 | 대체됨([0015 홈 여행 조건 폼을 가운데에 배치](0015-center-trip-form.md)) |
| 결정일 | 2026-11-24 |
| 결정한 사람 | 학생 |
| 관련 문서 | [0012 홈 여행 조건 입력 간소화](0012-simplify-trip-form.md) |

## 배경

필드 수에 비해 폼이 넓고, 폼 아래 지역 버튼이 별도 공간을 차지한다.

## 선택지

| 선택지 | 장점 | 단점 | 프론트엔드만으로 가능 |
|---|---|---|---|
| 기존 폭에서 필드만 제거 | 배치 수정 범위가 작음 | 입력칸이 여전히 넓음 | 가능 |
| 오른쪽에 좁은 폼 배치 | 짧은 입력을 모아서 볼 수 있음 | 모바일의 날짜 입력 너비를 확인해야 함 | 가능 |

## 결정

여행 조건 폼을 오른쪽에 배치한다. 날짜 두 칸과 인원 두 칸은 각각 한 줄에 둔다. 별도 지역 선택, 선호 교통수단, 장소 찾기 버튼은 제거한다.

## 근거

기존 지역 제안과 Enter 장소 검색을 입력칸에서 사용할 수 있다.

## 영향

- 새 여행 검색에 선호 교통수단의 빈 값을 전달한다.
- 날짜와 인원 입력은 모바일에서도 각각 한 줄을 사용한다.

## 후속 확인

- 데스크톱과 모바일에서 장소 선택과 여행 검색을 확인한다.

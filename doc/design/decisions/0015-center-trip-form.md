# 0015. 홈 여행 조건 폼을 가운데에 배치

| 항목 | 내용 |
|---|---|
| 상태 | 대체됨([0016 여행 조건을 오른쪽 상단에 확대 배치](0016-home-trip-panel.md)) |
| 결정일 | 2026-11-24 |
| 결정한 사람 | 학생 |
| 관련 문서 | [0014 홈 여행 조건 폼의 폭과 입력 줄 정리](0014-compact-trip-form.md) |

## 배경

학생이 전달한 배치 스케치에서 카드와 검색 버튼은 가운데에 있고, 입력은 두 칸씩 세 줄이다.

## 선택지

| 선택지 | 장점 | 단점 | 프론트엔드만으로 가능 |
|---|---|---|---|
| 폼만 가운데로 이동 | 기존 입력 배치 유지 | 모바일에서는 스케치와 배열이 다름 | 가능 |
| 입력과 버튼 배치도 맞춤 | 두 화면 폭에서 같은 입력 순서와 배열 | 좁은 화면에서 날짜 입력 폭 확인 필요 | 가능 |

## 결정

카드와 검색 버튼을 가운데에 배치하고 두 칸씩 세 줄을 유지한다.

## 근거

입력 짝과 버튼의 상대적인 위치를 학생이 제공한 스케치에 맞춘다.

## 영향

- 홈 폼의 배치와 검색 버튼 너비를 바꾼다.

## 후속 확인

- 데스크톱과 모바일 모두에서 입력 두 칸과 검색 버튼 가운데 정렬을 확인한다.

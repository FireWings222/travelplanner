# 0008. 지도는 카카오맵으로 구현

| 항목 | 내용 |
|---|---|
| 상태 | 결정 |
| 결정일 | 2026-11-23 |
| 결정한 사람 | 지도 교사 |
| 관련 문서 | [0006 참고 서비스](0006-design-references.md), [0007 시안 선택](0007-draft-selection.md) |

## 배경

시안 A, B의 지도는 응답 좌표와 단순한 해안선 다각형으로 그린 SVG 약도다. 실제 앱에서 지도를 어떤 방식으로 구현할지 정해야 했다.

현재 앱은 `static/js/route-map.js`에서 카카오맵 JavaScript SDK를 불러와 마커와 노선 선(`Polyline`)을 그리고, 실제 버스, 지하철 노선 좌표는 `/api/routes/geometry`에서 받는다. 카카오맵 키(`KAKAO_MAP_JS_KEY`)가 없으면 지도가 표시되지 않는다.

## 선택지

| 선택지 | 장점 | 단점 | 프론트엔드만으로 가능 |
|---|---|---|---|
| A. 카카오맵 | 실제 길, 건물, 확대와 이동이 있는 지도, 앱에 이미 연동 코드 있음 | 키가 없으면 지도가 안 보임, 지도 바탕색은 바꿀 수 없음 | 가능 |
| B. SVG 약도 | 키 없이 항상 보임, 색과 표현을 자유롭게 정함 | 상세 지도가 없어 실제 여행 계획에 쓸모가 거의 없음 | 가능 |
| C. 키가 있으면 카카오맵, 없으면 SVG 약도 | 어떤 환경에서도 지도가 보임 | 두 방식을 모두 유지해야 해 코드가 늘어남 | 가능 |

## 결정

실제 앱의 지도는 카카오맵으로 구현한다. SVG 약도는 시안 표현용으로만 쓰고 앱에는 넣지 않는다. 포트폴리오 시연은 카카오맵 키를 넣고 실행한다.

## 근거

지도 교사 의견: "SVG로 지도를 그리면 포트폴리오라고 해도 실용성이 하나도 없다." 여행 계획 앱에서 지도는 실제 위치와 동선을 확인하는 도구이므로 실제 지도가 필요하다.

## 영향

- 시안의 지도 위 요소(경로 선, Rome2Rio식 이름표, 날짜 색 번호 핀)는 카카오맵의 `Polyline`, `CustomOverlay`, 마커로 구현한다.
- 시안의 바다, 땅 색은 카카오맵에서 재현할 수 없다. 색 조합은 지도 위에 올리는 요소에만 적용한다.
- 키가 없을 때는 지도 대신 키 설정 안내를 보여 준다(현재 앱 동작 유지). 키 없는 화면을 따로 꾸미지 않는다.
- 0006의 "키가 없을 때도 보이도록 응답 좌표로 약도를 직접 그린다"는 이 결정으로 바뀐다.

## 후속 확인

- [ ] `CustomOverlay`로 시안의 이름표와 날짜 색 번호 핀을 표현할 수 있는지 구현 단계에서 확인
- [ ] 경로 카드 선택, 장소 순서 변경 때 지도 범위와 선이 바로 바뀌는지 확인
- [ ] 시연 환경의 카카오 JavaScript SDK 도메인 등록 확인

## 배경

이동 경로에서 자가용, 택시, 시외·고속버스와 함께 열차를 비교할 수 있어야 합니다.

## 선택지

| 선택지 | 장점 | 단점 | 프론트엔드만으로 가능 |
|---|---|---|---|
| A. 기존 ODsay 도시 간 응답 활용 | 한 응답에서 열차와 버스 후보를 읽습니다. | 공급자가 반환한 노선과 운임만 비교할 수 있습니다. | 불가 |
| B. 별도 철도 API 연동 | 운영사별 정보를 활용할 수 있습니다. | 별도 데이터 제공 범위에 맞춰 연동해야 합니다. | 불가 |

## 결정

기존 ODsay 도시 간 응답으로 KTX, SRT, 일반열차 후보를 추가합니다. 이동 경로 카드와 견적에 역 간 비용과 시간을 구분해 표시합니다.

## 근거

ODsay 도시 간 응답에는 열차 종류, 승하차 역명과 좌표, 전체 시간과 요금이 포함됩니다. [ODsay API 문서](https://lab.odsay.com/guide/releaseReference?platform=web)

## 영향

- 철도 색 점선으로 역을 연결합니다. 역과 여행지 사이의 접근 경로는 조회 가능한 구간을 지도에 표시합니다.
- 이동 경로와 현지 일정의 왕복 견적에 역 간 기준을 표시합니다.

## 후속 확인

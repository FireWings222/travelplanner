## 배경

ODsay의 시외버스 검색은 요금과 탑승 터미널을 알려 줍니다. 이동 경로 화면에서는 사용자가 고른 출발지와 목적지 사이에 버스를 타는 위치와 접근 경로도 확인할 수 있어야 합니다.

## 선택지

| 선택지 | 장점 | 단점 | 프론트엔드만으로 가능 |
|---|---|---|---|
| A. 터미널 연결선과 접근 경로 | 승차 위치와 터미널에 가는 경로가 보입니다. | 접근 경로를 별도로 조회합니다. | 불가 |
| B. 터미널 위치만 표시 | 지도에 필요한 조회가 적습니다. | 터미널까지 가는 방법을 지도에서 확인하기 어렵습니다. | 불가 |

## 결정

터미널 사이를 점선으로 연결합니다. 터미널과 여행지 사이에는 길찾기 응답이 있는 구간을 교통수단별로 표시합니다.

## 근거

카카오맵 웹의 성남종합버스터미널에서 강릉시외버스터미널까지 가는 시외버스 상세 화면에서 두 터미널을 연결하는 직선을 확인했습니다. ODsay 검색 문서에는 터미널의 출발·도착 좌표가 포함되어 있습니다. [ODsay API 문서](https://lab.odsay.com/guide/releaseReference?platform=web)

## 영향

- 이동 경로 화면에서 승차·하차 위치와 접근 경로를 볼 수 있습니다.
- 경로 조회 API와 지도 렌더링을 바꿉니다. 요금 비교는 터미널 간 운임과 시간으로 계산합니다.

## 후속 확인

- [ ] API 키가 설정된 환경에서 성남에서 강릉으로 가는 시외버스의 승차 위치와 접근 경로를 확인합니다.
